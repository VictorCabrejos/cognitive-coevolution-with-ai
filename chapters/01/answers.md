## Activity self-review

### One defensible response

Reminder: “Please bring a reusable cup; a paper cup is available if needed.” The proposed attendance restriction has no support in the source. A faithful notebook reminder likewise keeps spare paper available. A useful learning note names the unsupported condition and explains how to look for one next time.

### Five-point review

Give yourself one point for each criterion your work demonstrates. A different conclusion can earn the point when it meets the criterion and is supported by the supplied information.

1. The first reminder preserves both source conditions.
2. The unsupported attendance restriction is identified with source support.
3. Any assisted criticism is evaluated rather than adopted automatically.
4. The changed reminder is attempted with the earlier answer closed.
5. The learning note keeps observed performance separate from lasting-learning claims.

**4–5:** identify one limit or improvement before reusing the work. **2–3:** revise one missing element and explain the change. **0–1:** return to the source card and work through one condition before expanding the task.

This is a practice aid, not a validated measure of competence, learning or health. Evaluate the reasoning rather than agreement with a philosophy or confidence in a response.
