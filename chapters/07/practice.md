## Write a handoff that can survive a changed condition

**Time:** about 15 minutes. **Materials:** paper or a plain document; an assistant is optional.

### Source card

Fictional decision: use one opening example with two modifications because practice time is limited and the extension requires a prerequisite not yet taught. No learner trial has taken place. The current worksheet accidentally contains five modifications. A temporary chat request said “be very brief”; no permanent preference was established.

### Steps

1. Checkpoint (4 minutes): write Decision, Basis, Open and Next. Include the untested question about what learners can explain.
2. Rehydrate (3 minutes): write a short handoff to a new helper identifying the current decision, the worksheet mismatch and the next task. Do not copy the entire imagined chat.
3. Inspect (3 minutes): specify what you would check in the revised worksheet to learn whether the decision was applied. Repeating the note is not the same as changing the worksheet.
4. Change (3 minutes): new information says the prerequisite has now been taught, but practice time is still limited. Mark which reason is challenged, what remains applicable and what needs review before changing the exercise.
5. Portability check (2 minutes): read the note as someone with no old-chat access. Remove unnecessary background and keep enough basis to understand and revise the decision.

### Expected deliverable

A four-part checkpoint, a returning-helper brief and a clearly marked response to the changed condition.

### Reflection checklist

- [ ] Does the record explain why the decision was made?
- [ ] Is untested learning still marked as open?
- [ ] Does the next task resolve the two-versus-five mismatch?
- [ ] Can a new reader distinguish current decisions, temporary requests and changed conditions?

Keep your first attempt before consulting the [sample response and rubric](answers.md#activity-self-review). You can pause, save an open question and return later.
