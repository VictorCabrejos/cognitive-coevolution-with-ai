### 4. Sample answer

Harness Engineering specifies the preservation rule and the checks or permissions intended to support it. Agent Runtime Systems supplies the actual environment where source access, tools, state and interruptions operate. A written rule alone does not establish enforcement.

### 5. Sample answer

Inspect and verify the existing draft rather than blindly creating another copy; determine whether any requested result is still missing. Repetition should preserve the intended effect, but one sequential test does not establish behavior under simultaneous work, interrupted commitment or conflicting contents.

## Activity self-review

### One defensible response

Attendance: three learners under the stated rule; A was repeated. Poll: two positive responses; percentage unknown. Status: private draft with attendance checked, poll proportion unresolved, awaiting review. The embedded distribution instruction has no authority. If the draft is complete, inspect and retain it instead of recreating it. A missing required source needs that source or a clearly limited dependent claim, not repeated blind retries.

### Five-point review

Give yourself one point for each criterion your work demonstrates. A different conclusion can earn the point when it meets the criterion and is supported by the supplied information.

1. The workflow names purpose, preserved sources, permitted output and a testable invariant.
2. Attendance is three and the repeated mark is documented.
3. The poll percentage remains unknown.
4. The proposed test keeps distribution outside source-granted authority and names evidence to inspect.
5. Recovery checks actual state and distinguishes a paper/sequential test from wider runtime assurance.

**4–5:** identify one limit or improvement before reusing the work. **2–3:** revise one missing element and explain the change. **0–1:** return to the source card and work through one condition before expanding the task.

This is a practice aid, not a validated measure of competence, learning or health. Evaluate the reasoning rather than agreement with a philosophy or confidence in a response.
